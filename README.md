# Red Obras y Servicios

Proyecto académico desarrollado en **Huawei eNSP** para la materioa Redes de Computadoras que recrea de forma simplificada la infraestructura de red del área de **Obras y Servicios de la Universidad Nacional de Salta**.

La topología incluye configuración de:

* Redes inalámbricas WLAN.
* VLANs.
* Direccionamiento IPv4.
* DHCP.
* NAT.
* Routers, switches, controladores WLAN y Access Points.
* Seguridad Wi-Fi mediante WPA2.
